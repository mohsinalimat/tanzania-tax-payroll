## TECHNICAL NOTES

### Employee Salary Slip Access (Self-Service)

**Implementation:**
```python
# Security: Filter by logged-in user
def get_employee_salary_slips(filters):
    employee = frappe.db.get_value("Employee",
        {"user_id": frappe.session.user}, "name")

    if not employee:
        frappe.throw("No employee record found for your user")

    # Force filter to own employee only
    filters["employee"] = employee

    return get_salary_slips(filters)
```
